# Dependency risk register

## DR-001 — React Router unstable RSC CSRF bypass

| Field                  | Record                                                                                                                                                                                                                                                                                                                                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Status                 | Open — the vulnerability is not fixed in the installed dependency                                                                                                                                                                                                                                                                                                                                     |
| Affected package       | `react-router` through the direct `react-router-dom` dependency                                                                                                                                                                                                                                                                                                                                       |
| Installed version      | `react-router-dom` 7.18.1 and `react-router` 7.18.1                                                                                                                                                                                                                                                                                                                                                   |
| Advisory               | GHSA-qwww-vcr4-c8h2                                                                                                                                                                                                                                                                                                                                                                                   |
| Severity               | High                                                                                                                                                                                                                                                                                                                                                                                                  |
| Affected functionality | CSRF handling in unstable React Server Components action and server-action request processing                                                                                                                                                                                                                                                                                                         |
| SecureCare usage       | SecureCare is a client-rendered Vite application. It does not use React Server Components, React Router framework server rendering, route actions or server actions.                                                                                                                                                                                                                                  |
| Present exposure       | `npm audit` correctly reports the vulnerable package range. The vulnerable RSC execution path is not present in SecureCare, so the current application is not known to expose the affected action-processing endpoint. This is an applicability assessment, not a claim that the dependency is fixed.                                                                                                 |
| Temporary mitigation   | Do not introduce unstable RSC APIs, React Router server actions or framework server rendering. Keep all state-changing API requests behind the backend's synchroniser CSRF token, strict origin allowlist and `SameSite=Strict` cookies. Review dependency audit output on every CI run.                                                                                                              |
| Upgrade plan           | On 26 July 2026 the configured npm registry reported 7.18.1 as its latest available release and returned `E404` for 8.3.0. Do not force the audit's downgrade to 7.11.0 or an unavailable major release. Upgrade to the first patched, registry-available compatible release, then run TypeScript, lint, full tests, production build, route smoke tests and `npm audit` before claiming remediation. |
| Recorded               | 25 July 2026                                                                                                                                                                                                                                                                                                                                                                                          |
| Last reassessed        | 26 July 2026: `npm ls` confirmed 7.18.1; `npm audit` still reported two High findings; `npm view` found no patched compatible registry release. SecureCare still contains no RSC, server-action or framework-action implementation.                                                                                                                                                                   |
| Review date            | 1 August 2026, or immediately when a patched package becomes available                                                                                                                                                                                                                                                                                                                                |

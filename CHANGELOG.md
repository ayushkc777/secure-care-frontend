# Changelog

## 0.2.0 - 2026-07-27

- Standardised API paths under the central `/api/v1` Axios base and added build guards.
- Added email verification, resend, forgot/reset and authenticated password-change journeys.
- Added privacy-safe error reporting with request-correlation support.
- Added DOM interaction, keyboard, axe, coverage and production Playwright verification.
- Added an ESLint accessibility ruleset and labelled focusable table regions.
